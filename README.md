# Plagiarism Attack:
Our plagiarism attack is a **general, training-free, untargeted** attack on copyrighted data. It exploits the attention mechanisms underlying advanced neural models to remove copyright markers, ranging from **invisible watermarks** to **visible signatures**.

_Example: plagiarize Elon Musk portrait_

These attacked images resemble Elon Musk, but none of these can be him without complicated facial surgery or genetic engineering :)

**Attack pipeline:**
Our attack adds shims to anchor variable to diverge the trajectory of the copyrighted data and introduce different level of semantic alterations to bypass copyright protection. As shown below, we can generate a semantic similar plagiarized image **without** knowing the prompt or watermarking methods of target image. More details can be seen in our [poster](https://github.com/zzzucf/Neural-Plagiarism/blob/main/images/iccv25_poster_neural_plagiarism.png) and [paper](https://openaccess.thecvf.com/content/ICCV2025/papers/Zou_Attention_to_Neural_Plagiarism_Diffusion_Models_Can_Plagiarize_Your_Copyrighted_ICCV_2025_paper.pdf).

## Run an example

See [examples](examples/README.md) for a single-image configuration, existing illustrations, and the input / reconstruction / output report generated by the runner.

Check the configuration without loading models or installing the deep-learning stack:

```bash
python run_attack.py --target_folder samples --start 0 --end 1 --start_step 15 --k 25 45 --eps 10 --iters 10 --output_folder outputs/portrait-example --dry-run
```

After validating the model environment, remove `--dry-run` to execute. Each completed result is added to `outputs/portrait-example/index.html`, with configuration and seed metadata alongside it. GPU execution of this refreshed runner is not yet validated. See the [environment and evaluation notes](examples/README.md#run-the-configuration).

The old commands referenced `optimize_latent_images_folder.py`, which is absent from this repository. The old invisible-watermark example also used an unavailable `--noisy_start` flag. Watermark embedding and detection remain disabled in the current runner; the example gallery does not report detection success rates.
